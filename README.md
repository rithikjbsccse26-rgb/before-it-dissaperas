# Before It Disappears

A simple digital memory archive made with HTML, CSS and JavaScript.

## Project files

- `index.html` — home page and memory submission form
- `memories.html` — memory archive page
- `style.css` — design and responsive layout
- `script.js` — form, search, filters, favourites, details and delete functions

## How to run

1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Use the Memories link to open the archive.

## Storage note

This prototype uses browser Local Storage. Memories saved on one browser are not automatically shared with other people or devices. Clearing browser data may remove saved memories. The sample photos use online image links and need an internet connection.
