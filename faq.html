Frequently asked questions

How do I add a memory?

Open Share, complete the title, place, category and story fields, then select Save this memory.

Do I need to add a photograph?

No. A photograph is optional. You can save a text-only memory.

Where are memories stored?

This frontend demonstration uses Local Storage in your browser.

Can I use the archive on another computer?

Not automatically. A backend and database would be needed to share data between users and devices.

How do I find a memory?

Use the search box and category filter on the Memories page.

How do favourites work?

On a memory card, select the heart button. Your favourite list is available from the Favourites page.
