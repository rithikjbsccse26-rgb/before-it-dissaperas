ABOUT THE PROJECT

Because little moments matter.

The idea and technology behind Before It Disappears.

Project overview

Before It Disappears is a frontend memory archive. It gives visitors a simple way to write about meaningful moments, connect them with places and optionally attach photographs.

01 · Preserve

Record a memory before its details fade.

02 · Explore

Search, filter and revisit stories.

03 · Remember

Collect favourite moments in one place.

Technologies used

  • HTML: creates the structure of each webpage.
  • CSS: controls colours, layout and responsive design.
  • JavaScript: handles form submissions and interactive features.
  • Local Storage: stores data in the current browser.
Project limitation: this frontend version does not use a server or shared database. Memories and profile details stay in the browser where they were entered.
