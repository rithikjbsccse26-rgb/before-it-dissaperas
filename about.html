OUR IDEA

What is Before It Disappears?

Before It Disappears is a digital memory archive. It lets people write about meaningful moments, add a location and optionally attach a photograph. The archive is designed to make memories easy to save and revisit.

01. Preserve

Write down a moment before its details fade away.

02. Explore

Browse the archive, search stories and filter by category.

03. Remember

Save favourite memories and revisit their stories.

HOW IT WORKS

Simple to use

  1. Open the Share page.
  2. Enter a memory title, place, category and story.
  3. Add a photograph if you want.
  4. Save it and find it on the Memories page.

TECHNOLOGY

Made with simple web tools

This prototype uses HTML to structure the pages, CSS to style them and JavaScript to handle memory submissions and archive features. Memories are saved in the browser using Local Storage.

Prototype note: saved memories are stored in the current browser. They are not automatically shared between different users or devices.
